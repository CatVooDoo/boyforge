# CRM Orders & Manual Order Creation (5Post)

## Управление заказами (CRM)

### Страница заказов (`boyforgeadmin/orders.php`)
- **Сводочная панель KPI (Metrics Bar)**:
  - 4 карточки аналитики: Всего заказов, Выручка оплаченных (₽), К отправке / В сборке, В доставке 5Post (с индикатором времени синхронизации).
- **Переключатель режимов отображения (View Switcher)**:
  - Мгновенное переключение между видами:
    - 📋 **Список (Таблица)**: Классический реестр с расширенной информацией, быстрым копированием контактов/треков и бейджами статусов.
    - 🗂️ **Канбан-доска**: 6 колонок стадий жизненного цикла (`Ожидают оплаты`, `К отправке / Сборка`, `В пути (5Post)`, `В пункте выдачи`, `Выполнен`, `Отменен / Возврат`). Каждая колонка отображает счетчик заказов и суммарную стоимость.
  - Сохранение выбранного режима в `localStorage` браузера (`bf_orders_view_mode`).
- **Интеллектуальная фильтрация и поиск**:
  - Быстрый живой поиск по номеру заказа, ФИО, телефону, названию товара, трек-номеру 5Post или адресу ПВЗ.
  - Интерактивные чипсы-фильтры со счетчиками (`Все`, `К отправке`, `В пути 5Post`, `В пункте выдачи`, `Оплаченные`, `Ручные`, `Ожидают оплаты`, `Отмененные`).
- **Синхронизация статусов с 5Post (с кэшированием на 5 минут)**:
  - Метод `FivePostClient::getOrderStatuses(array $senderOrderIds)` пакетно запрашивает актуальные статусы посылок через официальный шлюз `https://api-omni.x5.ru/api/v1/getOrderStatus`.
  - При каждом открытии страницы администратором срабатывает `syncFivepostOrders()`. Если с прошлой синхронизации прошло меньше 5 минут (300 сек), отдается мгновенный кэш без задержек.
  - Кнопка **"Обновить 5Post"** в шапке позволяет принудительно обновить статусы в один клик без перезагрузки всей страницы через `boyforgeadmin/api_sync_5post.php?force=1`.
  - Заказы автоматически распределяются по колонкам канбана в соответствии с ответами 5Post (`APPROVED`, `IN_PROCESS`, `PLACED_IN_POSTAMAT`, `DONE` и др.).
- **Модальное окно детального просмотра (`orderDetailModal`)**:
  - Визуальный прогресс-бар этапов жизненного цикла заказа (`Создан` -> `Оплачен` -> `В 5Post` -> `В ПВЗ` -> `Вручен`).
  - Быстрое копирование телефона и трек-номера в буфер обмена с всплывающим тостом.
  - Прямой переход к отслеживанию на официальном сайте `fivepost.ru`.
  - Отправка закрывающего чека 54-ФЗ с интеграцией сканера маркировки (Честный ЗНАК).
  - Ручная отправка в 5Post и отмена заказа.

### Модальное окно создания ручного заказа (`createManualModal`)
- **UI Карты 5Post**: Полная копия UI карты со страницы оформления заказа на сайте (`product.php`), включая:
  - Форму поиска города с лупой и скругленными краями, встроенную в серый блок `fivepost-map-wrapper`.
  - Кастомные маркеры карты (`bf-map-pin`), состоящие из круглого тела (`bf-pin-body`) с логотипом `pyaterochka.png` и красным хвостиком (`bf-pin-tail`).
  - Отключение системной обводки браузера через `outline: none !important;`.
  - Балун с кнопкой "Выбрать эту точку".
- **Интеграция с базой товаров**:
  - Каскадные выпадающие списки для выбора: **Товара**, **Пола** и **Размера**.
  - Автоматическая подстановка цены в `crPrice` и автовыбор пола/размера, если вариант единственный.

### API эндпоинты
- `boyforgeadmin/api_sync_5post.php` — пакетная синхронизация статусов с 5Post (кэш 5 мин, поддержка параметра `force=1`).
- `boyforgeadmin/api_create_manual_order.php` — создание ручного заказа и регистрация в 5Post.
- `boyforgeadmin/api_manual_5post.php` — ручная отправка ранее созданного заказа в 5Post.
- `boyforgeadmin/api_receipt.php` — фискализация и закрывающий чек 54-ФЗ с маркировкой.
- `boyforgeadmin/api_cancel_order.php` — отмена заказа.
- `boyforgeadmin/api_tg_settings.php` — сохранение настроек Telegram бота и канала.
