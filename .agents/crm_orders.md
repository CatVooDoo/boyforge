# CRM Orders & Manual Order Creation (5Post)

## Управление заказами (CRM)

### Модальное окно создания ручного заказа (`boyforgeadmin/orders.php`)
- **UI Карты 5Post**: Реализована полная копия UI карты со страницы оформления заказа на сайте (`product.php`), включая:
  - Форму поиска города с лупой и скругленными краями, встроенную в серый блок `fivepost-map-wrapper`.
  - Кастомные маркеры карты (`bf-map-pin`), состоящие из круглого тела (`bf-pin-body`) с логотипом `pyaterochka.png` и красным хвостиком (`bf-pin-tail`), полностью соответствующие `css/style.css`.
  - Отключение системной обводки (focus outline) браузера через `outline: none !important;` для предотвращения зеленых рамок в админ-панели (из-за `admin.css`).
  - Балун с кнопкой "Выбрать эту точку".
- **Интеграция с базой товаров**:
  - Реализованы каскадные выпадающие списки (dropdowns) для выбора: **Товара**, **Пола** и **Размера**.
  - При загрузке модального окна через PHP-запрос загружаются все активные товары (`products`) вместе с распарсенным JSON-полем `sizes`.
  - При выборе товара:
    - Цена автоматически подставляется в поле `crPrice` из поля `price_numeric`.
    - Список "Пол" разблокируется и заполняется ключами из `sizes`. Автоматически выбирается пол, если он всего один.
  - При выборе пола:
    - Список "Размер" разблокируется и заполняется размерами для выбранного пола. Автоматически выбирается размер, если он всего один.
  - Итоговый размер отправляется на сервер как конкатенация пола и размера (например, "Мужской S").

### API создания ручного заказа (`boyforgeadmin/api_create_manual_order.php`)
- Принимает данные формы и создает заказ в `orders`, а также автоматически создает заказ в сервисе 5Post, если выбрана точка.
- Все данные для 5Post передаются точно так же, как в `api/yookassa_webhook.php` (для обычных оплаченных заказов).
